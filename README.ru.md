# fix-roblox-thumbnails

[English](README.md) | **Русский**

Один `.bat`, который возвращает картинки в Roblox на российских провайдерах:
обложки игр (places), аватарки, иконки, скриншоты, превью в Studio.

```
fix-roblox-thumbnails.bat            установить
fix-roblox-thumbnails.bat /remove    убрать записи
fix-roblox-thumbnails.bat /rollback  вернуть hosts из бэкапа
fix-roblox-thumbnails.bat /help      справка
```

## Что сломано

Roblox отдаёт все картинки с `tr.rbxcdn.com`. С июля 2026 это имя перестало
резолвиться у российских провайдеров: DNS возвращает `CNAME` на
`trns1.rbxcdn.com`, а у того нет ни `A`, ни `AAAA` записи.

Проверено на живой машине, ноябрь 2026:

| Запрос | Ответ |
|---|---|
| системный DNS (роутер `192.168.1.1`) | `CNAME trns1.rbxcdn.com`, дальше пусто |
| `1.1.1.1` | то же, NODATA |
| `8.8.8.8` | то же, NODATA |
| Cloudflare DoH (JSON) | `Status: 0`, только CNAME, в Authority один SOA |
| `trns1.rbxcdn.com` A и AAAA | пусто и там, и там |

Сама зона жива: `setup.rbxcdn.com` спокойно уходит в CloudFront
(`54.192.35.x`), `c0.rbxcdn.com` — в Akamai (`23.73.2.x`). Сломано ровно одно
имя, а не зона и не провайдер.

Подставишь адрес руками — картинка приходит:

```
curl --resolve tr.rbxcdn.com:443:23.73.2.78 https://tr.rbxcdn.com/180DAY-.../150/150/.../Png/noFilter
HTTP/1.1 200 OK, image/Png, 3739 bytes
```

В логе клиента это выглядит так:

```
[DFLog::HttpTraceError] CURLOPT_ERRORBUFFER: Could not resolve host: tr.rbxcdn.com
HttpResponse(#330 ...) time:11.6ms error:2 message:HttpError: DnsResolve
```

Названия, рейтинги и онлайн при этом на месте — они ходят по API `*.roblox.com`,
который резолвится нормально. Поэтому симптом узнаётся сразу: текст есть,
картинок нет.

## Почему обход DPI тут не помогает

`winws` из zapret ломает DPI в уже установленном соединении — ему нужен IP.
Когда DNS не отдаёт адрес, десинкать нечего: ни одна стратегия, ни турнир
стратегий, ни правка списков в этой ситуации не работают. Это задача уровня
резолва, а не пакетов.

## Что делает скрипт

1. Смотрит, нет ли уже записей для `tr.rbxcdn.com`. Если есть — ничего не
   меняет и даже не спрашивает UAC.
2. Делает бэкап `hosts` в `%USERPROFILE%\roblox-thumbnails-fix\hosts-<дата>.txt`.
3. Проверяет каждый адрес из списка по HTTPS (`curl --resolve`) и пишет только
   те, что реально ответили. Если не ответил никто — берёт список из скрипта
   и предупреждает.
4. Дописывает блок с комментарием и датой в `hosts`.
5. Сбрасывает DNS-кэш и показывает `ping` для проверки.

Повторный запуск безопасен. `/remove` вырезает строки с доменом, перед этим
сделав копию файла; если после вырезания `hosts` получается подозрительно
пустым — отменяет операцию и ничего не пишет.

## После установки

Полностью закрыть Roblox и открыть снова. Клиент кэширует неудачные запросы и
сам не переспросит — без перезапуска серые квадраты останутся.

## Оговорки

- Адреса — CDN (CloudFront и Akamai), они меняются. Если через месяцы снова
  серо: `/remove` и запуск заново. Список — переменная `IPS` в начале скрипта.
- `hosts` действует на всю систему, включая сайт и Studio. Здесь это как раз
  то, что нужно: ломались все три.
- Из зависимостей только `curl.exe`, он есть в Windows 10 и 11 из коробки.
  Если его нет, скрипт пишет список без проверки.
- Скрипт ничего не отправляет наружу и не трогает ничего, кроме `hosts` и
  своей папки с бэкапами.
